## Что делаем
1. **State-machine запуска** (чистый C#, тестируемый): Idle → взаимодействие с
   контролом C → Charging(C): заряд 0→1 за 5 с удержания/вращения; отпустил →
   спад до 0 за ~1 с (назад не копится); заряд=1 → запуск игры слота C.
   **Эксклюзивность:** пока заряд C > 0, остальные контролы игнорируются.
   Времена — в launcher-config.json (5.0 / 1.0 дефолт).
2. **Визуал:** прогресс-бар заряда + «дождь объектов» — экран заполняется
   падающими объектами пропорционально заряду (простые цветные спрайты со
   значком/цветом слота; тематические объекты игр — позже из манифестов),
   отпустил → объекты исчезают вместе со спадом.
3. Меню из hub-v0 остаётся (список = карта слотов); удержание работает с любого
   экрана меню: зажал клавишу слота → шкала растёт поверх. Установленный слот
   (TestGame) по 100% запускается; planned-слот на 100% показывает «скоро»
   и сбрасывается.
4. Клавиатура (симуляция контролов из пакета): удержание клавиши слота =
   удержание контрола; крутилка = крутить колесо мыши.
5. Тесты: EditMode — вся state-machine (рост/спад/эксклюзивность/пороги);
   PlayMode — шкала видима и растёт, дождь появляется/исчезает, 5с удержания
   RedButton-слота запускает TestGame, planned-слот не запускает.

## Прогресс (2026-07-25, ночной прогон — реализация)

Реализовано поверх hub-v0 без изменения его кода/тестов.

**Новые файлы (Assets/_Project/Scripts/Hub/):**
- `ControlReadings.cs` — engine-free снимок сырых значений контролов за кадр.
- `LaunchControl.cs` — enum контрола слота + разбор `controlName` (неизвестное → `None`, мёртвый слот, не краш).
- `LaunchTuning.cs` — коэффициенты (charge/decay сек + пороги) с дефолтами 5.0/1.0 и `Normalized()` (любое ≤0 → дефолт; страхует частичный JSON).
- `LaunchInputSampler.cs` — чистый: сырьё → per-slot «engaged» по правилам §2.3 (кнопки=held; датчики > порог; джойстик |вектор| > порог; крутилка |Δ°| > порог с таймаутом затухания).
- `LaunchChargeMachine.cs` — чистый детерминированный автомат: рост 0→1 за chargeSeconds, спад за decaySeconds, «назад не копится» (полный спад сбрасывает слот), эксклюзивность (первый слот с зарядом>0 блокирует остальные), одноразовый launch-edge на заполнении.
- `HoldToLaunchController.cs` — MonoBehaviour-адаптер + вид: читает только `ArcadeInput`, ведёт прогресс-бар + «дождь» цветных объектов (частота ∝ заряду, цвет слота), запускает installed-сцену или показывает оверлей «СКОРО …» + сброс для planned.

**Изменено:** `LauncherConfig.cs` (+`tuning`/`TuningOrDefault()`); `StreamingAssets/launcher-config.json` (+блок `tuning`); `HubMenu.unity` (компонент `HoldToLaunchController` добавлен на `HubLauncher` временным Editor-скриптом).

**Тесты (все зелёные headless, 6000.5.3f1):** EditMode 37/37 (16 hub-v0 + 21 новых: state-machine рост/спад/не-копится/эксклюзивность/launch-edge/reset; sampler пороги+крутилка-таймаут; tuning дефолты/normalize/частичный JSON).
