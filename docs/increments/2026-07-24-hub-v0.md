## Что делаем (what)

Хаб начинает существовать как приложение: подключает пакет контролов и умеет
показывать меню и гонять цикл «меню → сцена игры → назад в меню».

1. **Подключение `arcade-controls`:** в `Packages/manifest.json` хаба как
   `file:`-зависимость на локальный пакет
   (`projects/arcade-controls/.../com.aigamestudio.arcade-controls`) — автомат
   один PC, локальная ссылка честна для v0; на git-URL+тег переключимся, когда
   пакет уедет на GitHub (отдельное решение, записано здесь).
2. **`launcher-config.json`** в `StreamingAssets` (правится на диске без
   пересборки — музейный кейс): 7 слотов «контрол → игра» (имя, entry-сцена,
   статус installed/planned). Пока все игры planned, кроме встроенной тестовой.
3. **Меню-лаунчер v0:** сцена `HubMenu` (scene 0). Список 7 слотов из конфига;
   навигация через `ArcadeInput` (джойстик вверх/вниз = стрелки на клавиатуре,
   выбор = RedButton `1`). Вход в planned-слот → заглушка «скоро». Вход в
   тестовый слот → загрузка сцены; `MenuButton` (Esc) в ней → возврат в меню.
4. **`TestGame` сцена-заглушка** внутри хаба: минимальный «игровой» экран,
   живущий по контракту (стартует загрузкой сцены, умирает по MenuButton чисто,
   повторный вход = чистый старт). Доказывает цикл до прихода настоящих игр.
5. Тесты + ARCHITECTURE.md хаба.

НЕ в этом инкременте: hold-to-launch (шкала 5 с — этап ③), дождь объектов,
подключение настоящих игр, 3D-рендерер для ArcadePrototype.
