# Игровой автомат AI Game Studio — как запустить у себя

Это инструкция «с нуля»: что поставить, что склонировать, куда нажать. Ничего
собирать и компилировать руками не нужно — Unity скачает все игры сам.

Играть можно **сразу с клавиатуры**, платы (Arduino) не обязательны — про них
отдельный раздел в конце.

---

## Что понадобится

| Что | Зачем |
|-----|-------|
| **Unity 6000.5.3f1** | ровно эта версия; другие могут не открыть проект |
| **Unity Hub** | им ставится нужная версия Unity |
| **Git** | Unity сам скачивает игры из git-репозиториев, без git не соберётся |
| **Доступ к репозиториям GitHub** | они приватные, см. следующий раздел |

Мышь с колёсиком желательна: колесо мыши изображает «крутилку» автомата.

### Ставим Unity

1. Скачай и установи **Unity Hub**: https://unity.com/download
2. В Hub: вкладка **Installs → Install Editor → Archive** (или ссылка
   «download archive») и найди версию **6000.5.3f1**.
   Прямая ссылка для Hub: `unityhub://6000.5.3f1`
3. Модули можно не добавлять — играть будем прямо в редакторе.

### Проверяем git

Открой терминал и набери `git --version`. Если команды нет:

* **macOS**: `xcode-select --install` (поставит git) или https://git-scm.com/download/mac
* **Windows**: https://git-scm.com/download/win

## Доступ к репозиториям (важно!)

Все репозитории **приватные**. Чтобы что-то скачалось, нужно:

1. Попросить в студии **инвайт на свой GitHub-аккаунт** в эти репозитории:
   `arcade-hub`, `arcade-controls`, `home-alone`, `life-choices`, `meditation`,
   `EndlessSisyphusUnity`, `factory_game`, `lady_bug` (все в аккаунте `Puzanira`).
2. Принять приглашения (придут на почту / появятся на github.com).
3. **Залогинить git один раз**, иначе Unity молча не скачает пакеты.

Самый простой способ — GitHub CLI:

```bash
# macOS:  brew install gh      Windows: winget install GitHub.cli
gh auth login          # выбери HTTPS и вход через браузер
gh auth setup-git      # ВАЖНО: научит git пользоваться этим логином
```

Альтернатива без `gh` — **Personal Access Token**: на github.com →
Settings → Developer settings → Personal access tokens → Tokens (classic) →
Generate new token, галочка **repo**. Токен вводится вместо пароля, когда git
первый раз спросит логин; он сохранится в системном хранилище паролей.

> Проверка, что доступ есть:
> `git ls-remote https://github.com/Puzanira/arcade-hub.git`
> — должен напечатать строчки с хешами, а не «Repository not found».

## Скачиваем и открываем

```bash
git clone -b handout https://github.com/Puzanira/arcade-hub.git
```

1. Открой **Unity Hub → Add → Add project from disk** и выбери папку
   **`arcade-hub/components/unity-game`** (именно её, не корень репозитория).
2. Запусти проект. **Первый запуск долгий (5–20 минут)**: Unity качает шесть
   игр из GitHub и импортирует их. В нижнем правом углу крутится прогресс.
   Если git спросит логин/пароль — это тот самый доступ из прошлого раздела.
3. Когда проект открылся, в окне **Project** найди и открой сцену
   **`Assets/_Project/Scenes/HubMenu.unity`** (двойной клик).
4. Нажми **Play** (треугольник сверху).

Дальше всё происходит внутри игры: заставка, меню автомата, запуск игр,
возврат в меню.

## Управление с клавиатуры

У автомата 8 «железных» органов управления. Без плат их изображает клавиатура
и мышь:

| Орган автомата | Клавиша |
|---|---|
| **Крутилка** | **колесо мыши** (крутить) |
| **Красная кнопка** | **`Э`** — клавиша слева от Enter (на латинской раскладке это `'`) |
| **Зелёная кнопка** | **`Enter`** |
| **Кнопка «!»** | **`1`** |
| **Кнопка «меню»** | **`Esc`** |
| **Джойстик** | **стрелки** ← ↑ ↓ → |
| **Датчик высоты A** (левая ладонь) | **`Q`** — поднять, **`A`** — опустить |
| **Датчик высоты B** (правая ладонь) | **`E`** — поднять, **`D`** — опустить |

Про «датчики высоты»: это бесконтактные датчики, над которыми на автомате
держат ладонь. С клавиатуры значение плавно растёт, пока держишь клавишу
«вверх», падает, пока держишь «вниз», и **само возвращается к нулю**, если
не держать ничего (как убранная рука).

Раскладка не зашита в код, а лежит в файле
`Runtime/Resources/ArcadeControls/default-keyboard-mapping.json` пакета
`arcade-controls`. В скачанном виде пакет доступен только для чтения
(`components/unity-game/Library/PackageCache/…`), так что менять клавиши
«на месте» нельзя — это делается в самом репозитории `arcade-controls`.

### Как выбрать игру в меню

Каждая игра «висит» на своём органе управления. Чтобы запустить —
**подержи / покрути нужный орган примерно 5 секунд**, полоска зарядки
дойдёт до конца и игра стартует.

| Игра | Чем запускается | Клавиатура |
|---|---|---|
| **Бесконечный Сизиф** | крутилка | крутить колесо мыши |
| **Последняя смена** | красная кнопка | держать `Э` |
| **Спасибо, не надо** | зелёная кнопка | держать `Enter` |
| **Медитация в спешке** | джойстик | держать стрелку |
| **Lady Bug Hit The Road** | датчик высоты A | держать `Q` |
| **Кошачьи будни** | датчик высоты B | держать `E` |
| _Таблетка в космосе_ | кнопка «!» | пока не сделана |

**Выход из любой игры обратно в меню — `Esc`** (кнопка «меню» на автомате).
Работает в любой момент, даже посреди партии.

## Подключение плат (не обязательно)

Автомат управляется самодельными платами на Arduino, каждая втыкается в свой
USB-порт. Игра опрашивает порты сама: воткнул — заработало, выдернул —
вернулась клавиатура. Никаких настроек в игре нет.

Плат две:

* **Панель** — крутилка-энкодер и четыре кнопки (красная, зелёная, «!», меню).
  Собирается по уроку.
* **Плата коровки** — джойстик и два датчика расстояния под ладони (готовая,
  от автора игры Lady Bug).

Всё про сборку панели — схемы, пины, прошивка, проверка — в репозитории
**`arcade-controls`**:

* инструкция: **`docs/LESSON_WIRING.md`**
  https://github.com/Puzanira/arcade-controls/blob/main/docs/LESSON_WIRING.md
* прошивка для панели: **`Firmware/CabinetPanel/CabinetPanel.ino`**
  (заливается через Arduino IDE)

Короткая шпаргалка по пинам панели:

```
D2 = красная   D3 = зелёная   D4 = «!»   D5 = меню (TTP223, HIGH = касание)
D6 = энкодер CLK   D7 = энкодер DT   (+/VCC → 5V, GND → GND)
115200 бод.  Nano CH340: Board = Arduino Nano, Processor = ATmega328P
```

> ⚠️ **Порт читает только один Play за раз.** Если открыт второй Unity в
> режиме Play (или в Arduino IDE открыт Serial Monitor) — показания платы
> будут рваться у обоих. Держи запущенным что-то одно.

## Что пока не работает

* **Звука нет** в играх «Спасибо, не надо» и «Медитация в спешке» — он в
  разработке.
* Слот **«Таблетка в космосе»** (кнопка «!») пустой — игра ещё не сделана,
  в меню он показан как «скоро».
* Первый запуск проекта долгий: Unity выкачивает игры из GitHub. Дальше
  запускается быстро.

## Как обновиться до свежей версии

```bash
cd arcade-hub
git pull
```

Затем **переоткрой проект в Unity** (закрыть редактор и открыть заново).
Unity увидит новые версии игр в `Packages/manifest.json` и докачает их —
это опять может занять несколько минут.

Если Unity «залип» и не видит обновления — удали папки
`components/unity-game/Library` и `components/unity-game/Temp` и открой
проект заново. Ничего своего при этом не потеряется.

---

## Если что-то пошло не так

* **«Repository not found» / Unity ругается на `Package [com.aigamestudio.…]
  cannot be found`** — нет доступа к приватным репозиториям или git не
  залогинен. Вернись к разделу «Доступ к репозиториям».
* **«No 'git' executable was found»** — не установлен git (см. «Что
  понадобится»); после установки перезапусти Unity.
* **Проект открылся, но окно Game пустое** — не открыта сцена
  `Assets/_Project/Scenes/HubMenu.unity`.
* **Игра не запускается из меню** — держи нужную клавишу дольше, зарядка
  занимает ~5 секунд.
* **Нажатия не проходят** — кликни мышкой в окно **Game**, чтобы оно
  получило фокус ввода.
